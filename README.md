## Core Features

- Fetches board data tied to the current user and renders it in a dynamic Kanban grid (Backlog → To do → In progress → Review → Done)
- Create new tasks via a form/modal, persisted and instantly reflected on the board
- Edit action opens a modal pre-populated with the target task's current data
- Delete action requires confirmation before permanently removing a task
- Data aggregation utilities — skipped this sprint
- Charting/data visualization dashboard — skipped this sprint

---

## Board Overview

Each sprint tracks:
- Sprint name, date range, and progress percentage
- Velocity (points)
- Tasks organized into columns by status, with priority tags (Low / Medium / High) and assignee avatars
